ChatSeek · Apple Silicon Mac 开发者预览版

最低系统目标为 macOS 14（当前依赖要求）；读取流程仅在微信 4.1.15 / macOS 26.4 开发环境验证过，其他机器仍需实测。

1. 将 ChatSeek.app 复制到“应用程序”，双击启动。应用会启动本机后台并打开浏览器。
2. 在“模型与接入配置”填写自己的 API Base URL、文本模型 ID 和 API Key，费用自付。
   使用兼容 Chat Completions 的模型服务，不需要邀请码或项目作者的服务器。
   视觉模型为可选项，请填写支持图片输入的模型 ID；留空时只做文字问答。
3. 先在原版微信登录一次，再选择检测到的本机账号。
   正常退出微信，阅读并确认临时副本初始化说明后再执行初始化。
   程序会复制微信、重签临时副本并用 LLDB 启动，验证密钥后保存到本机。
   需要 Xcode Command Line Tools、系统 Python，以及 macOS 对实际启动应用的文件访问授权。
4. 初始化结束后重新打开原版微信；下载/检查本地 BGE 公共模型（约百 MB）。
5. 关闭配置窗口，在左侧填写好友完整昵称、备注或群名，选择后同步并提问。
6. 原文同步、关键词搜索和向量计算在本机完成。
   问题、规划所需历史、聊天证据、完整范围总结及按需媒体画面会直接发往你配置的 API。
   当前没有自动脱敏，SQLite 索引及权限受限的配置/密钥文件没有额外的应用层加密。
7. 关闭网页不会退出后台；从 Dock 或菜单栏“退出 ChatSeek”停止后台和同步。

数据位置：~/Library/Application Support/ChatSeek/
可从 ChatSeek 菜单“在 Finder 中显示数据”打开。
“清除本机聊天数据…”会在确认后删除 ChatSeek 的索引、问答和媒体，保留微信原始数据库、初始化密钥、模型和账号配置。
请勿将此数据目录或个人 .env 分享给其他使用者。

源码运行与打包是两种使用方式，均需用户自行完成微信初始化和个人模型配置。
默认构建包只有临时本机签名，尚未完成 Developer ID 签名与公证，其他 Mac 可能显示来源验证提示。
