访问权限说明

询问请求：提问、手动同步、切换会话或处理媒体前，先在 ChatSeek 内询问本次访问。已开启的后台持续同步保留原设置，可在“同步详情”中暂停。

完全访问：跳过 ChatSeek 内的确认。它不会自动取得 macOS 系统权限，也不会扩大当前选择的会话范围。

减少系统数据访问弹窗

  1. 打开“系统设置 → 隐私与安全性 → 完全磁盘访问权限”。
  2. 为启动后台的应用手动授权：通过 ChatGPT/Codex 启动时选择对应应用；通过终端启动时选择“终端”。
  3. 退出并重新启动获得授权的应用，再重新启动网页服务。

完全磁盘访问是系统授予启动应用的较大权限，范围不限于本会话。系统授权状态未自动检测，仍以 macOS 的设置和提示为准。
